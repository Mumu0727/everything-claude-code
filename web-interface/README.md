# JTCC Web界面 - 使用说明

## 概述

JTCC Web界面是一个可视化的命令浏览器，让您可以通过友好的图形界面来浏览和搜索所有可用的Claude Code命令、代理和技能。

## 快速开始

### 启动Web界面

```bash
# 基础启动（默认端口3000）
/web-interface

# 指定端口启动
/web-interface --port 8080

# 后台运行
/web-interface --daemon
```

启动后会自动在浏览器中打开 `http://localhost:3000`

### 界面导航

Web界面包含三个主要分区：

1. **命令 (Commands)** - 浏览所有可用的斜杠命令
2. **代理 (Agents)** - 查看专用工作流代理
3. **技能 (Skills)** - 了解领域知识和最佳实践

## 主要功能

### 🔍 智能搜索

- **实时搜索**: 在顶部搜索框输入关键词，立即显示匹配结果
- **搜索建议**: 输入时显示相关命令和类型建议
- **搜索历史**: 自动保存最近的搜索词，便于快速重用

使用技巧：
- 搜索命令名称：输入 "plan" 找到规划相关命令
- 搜索功能类型：输入 "test" 找到所有测试相关命令
- 搜索描述内容：输入 "代码审查" 找到相关功能

### 📊 分类筛选

在左侧边栏中，您可以按类型筛选命令：

- **测试 (Testing)** - TDD、测试覆盖率等
- **构建 (Build)** - 构建错误修复、部署等
- **规划 (Planning)** - 功能规划、架构设计等
- **审查 (Review)** - 代码审查、质量检查等
- **文档 (Documentation)** - 文档生成和更新
- **重构 (Refactoring)** - 代码重构和清理

### 📖 详细信息

点击任何命令卡片的"查看详情"按钮，可以看到：

- **完整描述** - 命令的详细说明
- **使用方法** - 具体的用法和参数
- **代码示例** - 实际使用案例
- **相关命令** - 相关的其他命令链接

### 🎨 界面定制

**主题切换**
- 点击右上角的月亮/太阳图标切换深色/浅色主题
- 主题选择会自动保存

**响应式设计**
- 自动适配桌面、平板和手机屏幕
- 在移动设备上侧边栏会自动折叠

## 快捷键

提升使用效率的键盘快捷键：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 快速聚焦到搜索框 |
| `Alt+1` | 切换到命令分区 |
| `Alt+2` | 切换到代理分区 |
| `Alt+3` | 切换到技能分区 |
| `Ctrl+R` | 刷新当前分区数据 |
| `Esc` | 关闭详情模态框或清除搜索 |

## 实用技巧

### 1. 快速找到命令

**按用途搜索**
- 想做测试？搜索 "test" 或 "tdd"
- 需要规划？搜索 "plan" 或 "design"
- 要修复bug？搜索 "fix" 或 "build"

**使用类型筛选**
- 勾选左侧的命令类型复选框
- 可以同时选择多个类型
- 点击"清除"按钮重置所有筛选

### 2. 复制命令

**从列表复制**
- 点击命令卡片上的"复制"按钮
- 自动复制格式：`/command-name`

**从详情页复制**
- 在详情模态框中点击"复制命令"按钮
- 复制完整的使用示例

### 3. 浏览相关内容

**查看相关命令**
- 在命令详情页面底部查看相关命令
- 点击相关命令标签直接跳转

**统计信息**
- 左侧边栏显示各类型命令的数量统计
- 查看最近更新的命令列表

### 4. 移动设备使用

**手机浏览**
- 侧边栏自动调整为顶部折叠菜单
- 触摸优化的交互体验
- 支持手势操作

## 故障排除

### 常见问题

**无法启动Web界面**
```bash
# 检查端口是否被占用
netstat -ano | findstr :3000

# 使用不同端口
/web-interface --port 8080
```

**搜索没有结果**
- 检查搜索词拼写
- 尝试更简短的关键词
- 使用类型筛选替代搜索

**页面加载缓慢**
- 使用 `Ctrl+R` 刷新页面
- 清除浏览器缓存
- 检查网络连接

**复制功能不工作**
- 确保浏览器支持剪贴板API
- 检查浏览器权限设置
- 使用手动选择复制作为备选

### 重置和清理

**清除搜索历史**
```javascript
// 在浏览器控制台中运行
localStorage.removeItem('jtcc_search_history')
```

**清除应用设置**
```javascript
// 在浏览器控制台中运行
localStorage.clear()
```

**重启Web服务**
```bash
# 停止当前服务（Ctrl+C）
# 然后重新启动
/web-interface
```

## 高级功能

### 开发模式

```bash
# 启用调试日志
/web-interface --dev

# 在浏览器控制台使用调试工具
window.jtccDebug
```

### 后台运行

```bash
# 在后台启动（适用于服务器部署）
/web-interface --daemon

# 检查运行状态
ps aux | grep web-interface

# 停止后台服务
kill <PID>
```

### 自定义配置

创建配置文件 `web-interface/config.json`：

```json
{
  "server": {
    "port": 3000,
    "host": "0.0.0.0"
  },
  "features": {
    "search": {
      "maxResults": 50,
      "minQueryLength": 1
    },
    "ui": {
      "theme": "dark",
      "itemsPerPage": 20
    }
  }
}
```

## 安全注意事项

### 网络安全

- 默认只绑定到 localhost
- 在生产环境中使用 `--host 0.0.0.0` 时要谨慎
- 建议在反向代理后面运行

### 数据安全

- Web界面只读取现有文件，不修改任何内容
- 不会暴露系统敏感信息
- 不需要管理员权限运行
